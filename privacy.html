Privacy Policy

This policy applies to the SPK Social Media Coach application only — a private analytics and content-planning dashboard for an authorized TikTok creator account. It is separate from the Datenschutzerklärung of this website.

Last updated: August 1, 2026

1. Purpose

SPK Social Media Coach is a private analytics and content-planning application for an authorized TikTok creator account.

2. Data accessed

With the user's permission, the application may access basic profile information, public video information and account statistics made available through TikTok's official APIs and approved scopes.

3. Use of data

Data is used to display analytics, compare content performance, support content planning and generate recommendations for the authorized user.

4. Data sharing

The application does not sell personal data. Data is not shared with advertisers or unrelated third parties.

5. Storage and security

Application data may be stored locally on the authorized user's device. Access credentials must be kept confidential and are used only to authenticate official API requests.

6. Data retention and deletion

The user may delete locally stored data by removing the application's database and configuration files. The user may also revoke TikTok authorization through their TikTok account settings.

7. Children's privacy

The application is not directed to children and is intended only for the authorized account owner or manager.
